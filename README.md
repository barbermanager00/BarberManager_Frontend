# BarberManager_Frontend

Frontend del sistema BarberManager para gestión de barberos, clientes y servicios.

## Descripción

Este repositorio contiene la interfaz web del proyecto BarberManager, desarrollada para ofrecer una experiencia visual para:

- inicio de sesión
- selección de rol
- pantalla de bienvenida
- gestión de empresa
- perfil de usuario
- flujo principal de la aplicación

## Estructura del proyecto

- `public/` - archivos públicos del frontend
- `views/` - vistas de la aplicación
- `public/index.php` - punto de entrada principal
- `public/js/app.js` - lógica de interacción del frontend

## Tecnologías

- HTML
- CSS
- JavaScript
- PHP

## Objetivo

Proveer la capa visual y de interacción del sistema BarberManager, conectándose con la lógica de negocio del backend y la API del proyecto.
